# CONFIG MODULE MAP

- SideEffects: Tidak ada; dokumentasi statis.

| File | Ekspor/Publik | Tanggung Jawab |
| --- | --- | --- |
| `config/commands-minimal.json` | `Not found` | Subset command minimal atau fallback untuk bot. |
